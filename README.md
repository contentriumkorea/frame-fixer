# Frame Fixer

시댄스 영상의 모든 프레임을 원래 순서대로 유지하면서 **23.976fps 또는 24fps**의 일정한 간격으로 다시 배치하는 Windows 앱입니다. PNG로 추출하거나 편집기에 한 장씩 나열할 필요가 없습니다.

## 다운로드

[최신 설치파일 받기](https://github.com/contentriumkorea/frame-fixer/releases/latest)에서 `FrameFixer-버전-Setup.exe`를 받으세요. `release-manifest.json`과 `.sig`는 앱 업데이트 검증용이므로 따로 열 필요가 없습니다.

**1.0.13 변경:** 프로그램과 설치파일 아이콘을 배경 없는 화이트 단색 프레임 심볼로 변경했습니다. 16~256px 아이콘을 포함하며, 기존 다크 UI·스크롤바와 변환 기능은 그대로 유지됩니다. 화이트 단색 특성상 밝은 배경에서는 대비가 낮을 수 있습니다.

1.0.11의 Contentrium 시작 이미지·실제 준비 상태 표시와 **변환 프레임 / 출력 파일명 / 저장 위치** 구역 구분도 그대로 유지됩니다.

1.0.10에서 도입한 Codex 스타일 다크 색상과 무료 워터마크 모드는 그대로 유지됩니다. 활성화 없이 길이 제한 없이 모든 기능을 사용할 수 있으며, 무료 출력 중앙에는 Contentrium 로고가 불투명도 20%로 들어갑니다. Activation 후 출력에는 워터마크가 없습니다. 기존 설정과 활성화 정보는 유지됩니다.

저장소 이름이 `frame-fixer`로 변경되어 **1.0.8 이하 사용자는 새 Setup EXE를 직접 받아 설치해야 합니다.** 기존 앱은 저장소 이름 변경 리디렉션을 보안상 차단합니다. 1.0.9부터는 앱 내 업데이트를 사용할 수 있습니다.

**1.0.5 설치가 ‘Video tools could not be prepared’로 멈췄다면 1.0.6 이상 설치파일을 새로 받아 실행하세요.** 1.0.5의 보안 통신 설정과 한글 오류 표시 문제를 수정했습니다. 기존 1.0.5 앱의 업데이트 확인도 연결에 실패할 수 있으므로, 이 경우 위 링크에서 직접 받으세요. 보안 설정을 끄거나 별도 영상 도구를 수동 설치할 필요는 없습니다.

- Windows 10/11 x64, .NET Framework 4.8 이상이 필요합니다.
- **최초 설치에는 인터넷이 필요합니다.** 설치 중 필요한 FFmpeg/FFprobe를 공급처에서 자동으로 다운로드하고 검증·연결합니다. 별도 다운로드 버튼이나 폴더 선택은 필요하지 않습니다.
- 설치 후에는 오프라인에서도 변환할 수 있습니다. 정상적인 기존 도구 설정은 재사용합니다.
- 현재 배포본은 Windows 코드 서명 인증서가 없는 버전입니다. 확인되지 않은 게시자 경고 또는 보안 정책에 따른 실행 차단이 발생할 수 있습니다. 보안 설정을 끄지 마세요. 아래 공식 저장소의 배포 파일인지 확인하세요.

공식 배포처: https://github.com/contentriumkorea/frame-fixer

## 사용법

1. 설치 후 시작 메뉴에서 **Frame Fixer**를 엽니다.
2. 영상 여러 개를 창에 끌어넣습니다.
3. 목표 FPS를 선택합니다. 기본값은 23.976fps(정확히 `24000/1001`)입니다.
4. 파일명과 저장 위치를 확인합니다. 기본 출력명은 `원본이름(23.976).mp4`이며 앞 이름과 괄호 안 이름을 수정할 수 있습니다. FPS·이름·저장 위치 변경은 모든 대기/실패 항목에 자동 반영됩니다. 분석 중이면 분석 완료 후 최신 설정을 반영하며, 이미 완료된 결과 파일과 경로는 바꾸지 않습니다. 별도의 전체 적용 버튼은 없습니다.
5. 오른쪽 아래 **N개 렌더** 또는 **렌더 시작**을 누릅니다. 파일별 진행률과 하단의 전체 진행률·경과 시간·예상 남은 시간을 확인할 수 있습니다.

원본 파일과 기존 출력 파일을 덮어쓰지 않습니다. 각 영상의 원본 픽셀 크기를 유지하므로 720p, 1080p, 4K, 세로 영상을 섞어 넣을 수 있습니다.

## 무료 이용과 오류 확인

- 활성화하지 않아도 **길이 제한 없이 모든 기능**을 사용할 수 있습니다. 무료 출력에는 중앙에 **불투명도 20%**의 Contentrium 로고가 들어갑니다. 로고는 화면 가로 약 22%이며 세로 크기도 제한합니다. 상단 **Activation**에서 **Activation Code**를 입력하고 **Activate**를 누르면 이후 출력의 워터마크가 제거됩니다. 활성화 정보는 다음 실행에도 유지되며 기존 출력 파일을 소급 변경하지 않습니다. 이 코드는 계정·결제·기기 수 제한이 아닌 오프라인 편의 기능이며, 코드 자체는 공개 안내나 오류 화면에 표시하지 않습니다.
- 변환 실패, 도구 준비, 업데이트 확인 등에서 **오류 상세**를 열면 필요한 진단 내용을 읽고 **내용 복사**로 직접 전달할 수 있습니다. 영상이나 오류 내용은 자동으로 업로드·전송하지 않습니다.
- 이전 버전의 출력 파일이나 이용 조건은 소급 변경하지 않습니다.

## 화질과 속도

프레임을 삭제·복제·보간하지 않습니다. 영상 길이는 `프레임 수 ÷ 목표 FPS`로 바뀝니다. AAC 오디오는 속도를 바꾸지 않고 시작점을 영상 0초에 맞춰 복사합니다.

무손실 H.264로 인코딩합니다. 활성화 출력은 원본 픽셀과 비교하고, 무료 출력은 **워터마크를 합성한 기준 영상**과 모든 디코딩 프레임 픽셀을 비교합니다. 워터마크가 들어간 부분은 의도적으로 원본과 다릅니다. 두 모드 모두 프레임 수·간격, 해상도·화면비·색 정보와 오디오를 검증한 후 저장합니다. 비트레이트와 용량 조건에 미달하거나 검증에 실패하면 완료 결과로 저장하지 않습니다. **무손실 출력은 원본보다 파일 용량이 크게 늘 수 있습니다.**

호환 NVIDIA GPU는 NVENC 무손실 인코딩을 사용하며, 지원하지 않는 환경이나 입력은 CPU 무손실 인코딩을 사용합니다. 원본 분석과 픽셀·오디오 검증에는 CPU와 저장장치도 사용하므로 전체 시간은 인코딩 시간보다 깁니다. 별도의 CUDA SDK는 필요하지 않습니다. 남은 시간은 실제 진행에 따른 추정치입니다.

지원 입력은 MP4의 H.264 8비트 SDR, AAC 오디오 또는 무음입니다. HDR·다른 비트 심도·다른 오디오 코덱·다중 트랙 등 지원하지 않는 입력은 임의로 바꾸지 않고 오류를 표시합니다. 무손실 H.264 프로파일은 일부 플레이어·편집기에서 열리지 않을 수 있으며, Premiere의 실제 가져오기·재생 호환성은 별도 확인이 필요합니다. 원본을 계속 보관하세요.

## 업데이트

앱을 켜면 백그라운드에서 새 버전을 확인합니다. 새 버전이 있을 때만 알림을 표시하며 **지금 업데이트**를 누르면 다운로드·검증 후 설치하고 다시 시작합니다. 알림을 닫고 계속 사용할 수도 있습니다. 상단 업데이트 버튼으로 수동 확인도 가능합니다. 업데이트 목록의 RSA 서명과 설치파일의 크기·SHA-256을 확인하며, 검증에 실패하면 설치하지 않습니다. 이 검증은 Windows 게시자 인증과는 별개입니다.

분석·렌더 중에는 시작 알림과 설치를 미룹니다. 수동으로 다운로드한 동안 작업이 진행 중이라면 작업 종료 후 **설치·다시 시작**을 누릅니다. 업데이트 후 설정과 파일 목록을 보존하며 렌더는 자동으로 시작하지 않습니다. 네트워크 오류는 ‘최신 버전’으로 표시하지 않고 수동 재확인과 오류 상세를 제공합니다.

설정은 `%AppData%\FrameFixer`, 영상 도구·업데이트 캐시는 `%LocalAppData%\FrameFixerData`에 저장합니다. 제거해도 설정·캐시·원본 영상은 남습니다. 최초 도구 다운로드가 실패하면 연결 상태를 확인하고 설치를 다시 시도하세요.

## 개인정보와 제3자 도구

영상은 외부로 업로드하지 않습니다. 외부 통신은 설치 중 도구 다운로드, 앱 시작 시 자동 업데이트 확인, 사용자가 실행한 업데이트 확인·다운로드 및 영상 도구 재다운로드에 사용됩니다. 시작 시 확인만으로 설치파일을 자동 다운로드하거나 설치하지 않습니다.

이 저장소는 Frame Fixer 설치파일·업데이트 확인 파일·안내만 배포합니다. 개발 소스와 사용자 영상, FFmpeg 바이너리는 포함하지 않습니다. FFmpeg/FFprobe는 [Gyan 공급처](https://www.gyan.dev/ffmpeg/builds/)의 고정 8.0 패키지에서 직접 받으며 공급처의 LICENSE·README를 로컬 도구 캐시에 보관합니다. [FFmpeg 프로젝트](https://ffmpeg.org/) 및 해당 도구의 라이선스는 각 권리자에게 귀속됩니다.
