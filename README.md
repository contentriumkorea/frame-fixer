# Frame Fixer

AI 생성 영상의 프레임을 일정하게 정리하고, 필요할 때 업스케일하는 Windows 앱입니다.

## 다운로드 · 설치

### [Frame Fixer 경량 설치파일 받기](https://github.com/contentriumkorea/frame-fixer/releases/download/installer-v1/FrameFixer-Setup.exe)

1. **FrameFixer-Setup.exe**를 실행합니다.
2. 최신 정식 버전을 자동으로 내려받고 검증합니다.
3. 이어서 열리는 설치 화면에서 이용 조건을 확인하고 설치합니다.
4. 바탕화면 또는 시작 메뉴의 **Frame Fixer**를 실행합니다.

설치파일은 특정 앱 버전에 고정되지 않습니다. 보관해 둔 같은 설치파일을 나중에 실행해도 그때의 최신 정식 버전을 확인합니다. 처음 설치할 때는 인터넷과 충분한 저장 공간이 필요하며, 정상적인 기존 AI 모델·영상 도구는 재사용합니다. 다운로드·검증·설치 실패 시 오류 내용을 확인하고 **다시 시도**할 수 있습니다.

**Windows 10/11 x64**를 지원합니다. 다른 운영체제나 CPU 구조에 맞는 패키지가 없으면 설치하지 않고 안내합니다. 현재 Windows 게시자 코드 서명이 없는 배포본이므로 보안 정책에 따라 경고나 차단이 발생할 수 있습니다. 보안 설정을 끄지 말고 공식 배포처를 확인하세요.

[최신 정식 버전과 변경 사항](https://github.com/contentriumkorea/frame-fixer/releases/latest) · [공식 저장소](https://github.com/contentriumkorea/frame-fixer)

## 주요 기능

- **프레임 보정:** 원본의 모든 프레임을 순서대로 유지하면서 선택한 FPS로 재배열합니다. 프레임을 삭제·복제·보간하지 않습니다.
- **업스케일:** 프레임 보정과 별도로 사용하거나, 프레임 보정 후 이어서 처리할 수 있습니다.
- **일괄 작업:** 영상 여러 개를 끌어넣고 파일명·저장 위치를 설정해 한 번에 처리합니다.
- **진행 확인:** 파일별·전체 진행률, 경과 시간·예상 남은 시간, PC 리소스를 표시합니다.
- **완료·오류 안내:** 전체 목록이 끝나면 알림음이 한 번 재생되며, 오류 상세를 복사해 전달할 수 있습니다.
- **Windows 통합:** 바탕화면·시작 메뉴 바로가기, 작업표시줄 표시·고정, 트레이의 창 열기·완전 종료를 지원합니다.

## 사용 방법

1. 영상을 작업 목록에 끌어넣습니다.
2. **프레임 보정 / 업스케일** 체크박스로 필요한 작업을 선택합니다.
3. 목표 FPS 또는 업스케일 크기를 정합니다.
4. 오른쪽 아래 **출력 설정**에서 파일명과 저장 위치를 확인합니다. 설정 변경은 대기 목록에 바로 적용됩니다.
5. **렌더 시작**을 누릅니다. 완료된 항목의 결과와 폴더를 열 수 있습니다.

기본 FPS는 23.976이며 24·25·29.97·30·50·59.94·60도 지원합니다. 기본 출력명은 `원본이름(23.976).mp4`입니다. 이름 앞부분과 괄호 안 이름을 수정할 수 있으며, 원본과 기존 출력 파일은 덮어쓰지 않습니다. 임시 작업은 선택한 저장 폴더를 사용합니다.

프레임 보정은 원본 해상도를 유지하며 영상 길이는 `프레임 수 ÷ 목표 FPS`로 바뀝니다. 오디오는 속도를 바꾸지 않고 영상 처음부터 재생합니다. 단독 업스케일은 원본 시간 정보와 오디오의 상대 시작점을 유지합니다.

## 업스케일 크기와 사양

**FHD 최소 / 4K 최소 / 원본 2배**를 선택할 수 있습니다. 최소 목표는 가로·세로 기준을 모두 충족하도록 원본 비율 기준으로 확대하며, 이미 두 기준을 만족하면 확대하지 않습니다. 자르기·여백 추가·축소 없이 필요한 축만 2픽셀 미만으로 짝수 올림합니다.

예: FHD 선택 시 1276×720 → **1920×1084**, 1280×720 → **1920×1080**, 1024×768 → **1920×1440**. 렌더 전에 파일별 예상 크기를 확인하세요.

업스케일은 **NVIDIA VRAM 16GB 이상 권장**입니다. 총 12GB와 현재 여유 10GB 이상을 검사하며, GPU 메모리 1GiB 여유 정책을 사용합니다. 다른 앱까지 포함한 PC 전체 사용량을 절대 한도로 통제하는 기능은 아닙니다. 최초 AI 준비는 약 6.88GB를 내려받으며 여유 공간 16GB 이상을 권장합니다. 모든 GPU·드라이버 조합을 검증한 것은 아닙니다.

AI는 새로운 디테일을 생성하므로 실제 원본 디테일 복원이나 모든 장면의 개선을 보장하지 않습니다. 생성한 화질을 보존하는 마지막 저장·검증 단계에는 CPU와 디스크도 사용합니다. 결과와 임시 작업 용량이 크게 늘 수 있습니다.

## 화질과 지원 입력

지원 입력은 **MP4의 H.264 8비트 SDR 영상과 AAC 오디오 또는 무음**입니다. 지원하지 않는 입력은 임의로 바꾸지 않고 이유를 표시합니다. 일반 프레임 보정은 가능한 경우 원본 압축 데이터를 유지하고, 불가능하면 무손실 인코딩 후 실제 프레임 픽셀·개수·시간·해상도·색 정보·오디오를 검증합니다.

파일 용량이나 비트레이트가 아닌 실제 화질·오디오 보존이 기준입니다. 원본 대비 용량 100–105%를 보장하지 않으며, 무손실 결과는 훨씬 커질 수 있습니다. 일부 편집기·플레이어에서 무손실 출력이 열리지 않을 수 있으므로 원본을 보관하세요.

## 무료 이용 · Activation

활성화하지 않아도 길이 제한 없이 모든 기능을 사용할 수 있습니다. 무료 출력 중앙에는 불투명도 20%의 Contentrium 로고가 들어갑니다. 상단 **Activation**에서 코드를 등록하면 이후 출력의 워터마크가 제거되며, 등록 상태는 다음 실행에도 유지됩니다. 기존 출력 파일은 소급 변경하지 않습니다.

## 업데이트 · 종료 · 제거

앱 시작 시 백그라운드로 업데이트를 확인합니다. 새 버전 알림의 **지금 업데이트**를 누르면 다운로드·검증 후 설치와 재시작을 연결합니다. 작업 중에는 안전한 시점까지 설치를 미루며, 나중에 업데이트할 수도 있습니다. 경량 설치기의 최초 설치 기능과 앱 내부 업데이트 기능은 별개입니다.

트레이에서 **Frame Fixer 열기** 또는 **완전 종료**를 선택할 수 있습니다. 작업 중 종료에는 취소 확인과 정리가 적용됩니다. Windows 설정의 **설치된 앱** 또는 제어판의 **프로그램 및 기능**에서 제거할 수 있으며, 앱 파일·등록 정보·생성한 바로가기는 정리합니다. 사용자 설정·Activation·캐시·원본·완료 영상은 보존합니다.

## 2.1.7 변경 사항

버전 고정 없는 경량 설치기를 추가하고 바탕화면 바로가기를 기본 생성하도록 변경했습니다. 트레이에서 창 열기와 완전 종료를 지원합니다. 기존 프레임 보정·업스케일·화질 검증 방식과 정상 AI 모델·영상 도구 캐시는 유지합니다.

## 개인정보 · 라이선스 고지

영상이나 오류 보고서는 자동으로 외부에 업로드하지 않습니다. 외부 통신은 필요한 구성요소·업데이트 확인과 다운로드에 사용합니다. 설치 화면에서 영상 도구·AI 구성요소 이용 조건을 확인하고 동의합니다. 오류 상세는 사용자가 직접 복사해 전달합니다.

사용하는 제3자 도구와 모델의 권리는 각 권리자에게 귀속됩니다. 영상 도구는 [Gyan 공급처](https://www.gyan.dev/ffmpeg/builds/)의 고정 패키지를 받고 [FFmpeg 라이선스](https://ffmpeg.org/legal.html)를 따릅니다. AI 모델은 공식 [SeedVR2 모델 저장소](https://huggingface.co/numz/SeedVR2_comfyUI)에서 고정 버전을 받습니다. 배포에 필요한 수정 소스·변경 고지·라이선스는 설치 폴더의 `ai`와 고지 파일에 보관합니다. [CUDA 이용 조건](https://docs.nvidia.com/cuda/archive/12.8.1/eula/index.html)과 [cuDNN 이용 조건](https://docs.nvidia.com/deeplearning/cudnn/backend/v9.10.2/reference/eula.html)도 설치 시 안내합니다.
