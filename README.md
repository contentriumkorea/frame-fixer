# Frame Fixer

**AI 생성 영상의 프레임을 일정하게, 편집은 더 간편하게.**

Frame Fixer는 AI로 생성한 영상의 불규칙한 프레임 간격을 **23.976fps 또는 24fps의 고정 프레임레이트(CFR)**로 정렬하는 Windows 앱입니다. 모든 프레임을 원래 순서대로 유지하며, PNG로 추출하거나 편집기에 한 장씩 나열할 필요가 없습니다.

특정 AI 영상 생성 서비스에 종속되지 않으며, 지원 형식에 맞는 영상을 변환할 수 있습니다. 기본 변환은 원본 해상도를 유지하고 프레임을 삭제·복제·보간하지 않습니다. 2.0에서는 선택형 **SeedVR2 AI 업스케일**도 사용할 수 있습니다.

## 다운로드

**2.0 변경:** 프레임 정렬 후 CUDA AI 업스케일, 원본 비율을 유지하는 FHD 이상 출력, CPU·RAM·GPU·VRAM 실시간 모니터를 추가했습니다. 일반 무손실 NVENC 설정도 실제 픽셀 보존 시험을 거쳐 조정했습니다. AI 준비·검증·복구와 설정 저장, 정상 파일을 계속 처리하는 배치 동작을 개선했습니다.

**1.0.19 변경:** 전체 렌더 작업이 끝나면 완료 알림음이 한 번 재생됩니다. 여러 파일을 변환해도 목록 종료 시 한 번만 울리며, 작업을 취소하면 재생하지 않습니다. 알림음은 앱에 포함되어 별도 파일 설정 없이 사용할 수 있습니다.

1.0.18의 원본 압축 데이터 유지 우선 처리와 무손실 인코딩 전환, 프레임 픽셀·오디오 보존 검증은 그대로 적용됩니다.

[최신 설치파일 받기](https://github.com/contentriumkorea/frame-fixer/releases/latest)에서 **Setup.exe 하나만** 받으세요. `release-manifest.json`, `.sig`, `runtime-1.zip` 등은 앱이 처리하는 파일이므로 직접 받거나 압축을 풀 필요가 없습니다.

**1.0.16 변경:** 오류·이름 충돌 항목은 이유를 남기고 정상 파일만 렌더할 수 있습니다. **실패 재시도**는 실패 항목만 다시 분석·렌더하며 새 대기 파일과 완료 결과는 건드리지 않습니다. 렌더 전 저장 공간을 확인하고 처리 중 공간 부족을 감지하면 해당 파일을 중단합니다. 전체 진행률·예상 남은 시간은 해상도와 프레임 수, 관측한 처리 속도를 반영합니다. 다른 영상이 렌더되는 동안에도 완료된 결과와 폴더를 열 수 있습니다.

1.0.15의 부드러운 모서리와 블랙·그레이 UI, 팝업의 제목·여백·버튼 정리는 유지됩니다. 변환 품질과 기존 설정·Activation 정보는 그대로 유지됩니다.

1.0.14의 버전별 화이트 아이콘과 바로가기 갱신 개선도 유지됩니다. Windows의 고정 항목·캐시 상태에 따라 아이콘 반영 시점은 달라질 수 있으며, 화이트 단색 특성상 밝은 배경에서는 대비가 낮을 수 있습니다.

1.0.11의 Contentrium 시작 이미지·실제 준비 상태 표시와 **변환 프레임 / 출력 파일명 / 저장 위치** 구역 구분도 그대로 유지됩니다.

1.0.10에서 도입한 Codex 스타일 다크 색상과 무료 워터마크 모드는 그대로 유지됩니다. 활성화 없이 길이 제한 없이 모든 기능을 사용할 수 있으며, 무료 출력 중앙에는 Contentrium 로고가 불투명도 20%로 들어갑니다. Activation 후 출력에는 워터마크가 없습니다. 기존 설정과 활성화 정보는 유지됩니다.

저장소 이름이 `frame-fixer`로 변경되어 **1.0.8 이하 사용자는 새 Setup EXE를 직접 받아 설치해야 합니다.** 기존 앱은 저장소 이름 변경 리디렉션을 보안상 차단합니다. 1.0.9부터는 앱 내 업데이트를 사용할 수 있습니다.

**1.0.5 설치가 ‘Video tools could not be prepared’로 멈췄다면 1.0.6 이상 설치파일을 새로 받아 실행하세요.** 1.0.5의 보안 통신 설정과 한글 오류 표시 문제를 수정했습니다. 기존 1.0.5 앱의 업데이트 확인도 연결에 실패할 수 있으므로, 이 경우 위 링크에서 직접 받으세요. 보안 설정을 끄거나 별도 영상 도구를 수동 설치할 필요는 없습니다.

- Windows 10/11 x64, .NET Framework 4.8 이상이 필요합니다.
- **최초 설치에는 인터넷이 필요합니다.** 설치 중 필요한 FFmpeg/FFprobe를 공급처에서 자동으로 다운로드하고 검증·연결합니다. 별도 다운로드 버튼이나 폴더 선택은 필요하지 않습니다.
- 설치 후에는 오프라인에서도 변환할 수 있습니다. 정상적인 기존 도구 설정은 재사용합니다.
- 현재 배포본은 Windows 코드 서명 인증서가 없는 버전입니다. 확인되지 않은 게시자 경고 또는 보안 정책에 따른 실행 차단이 발생할 수 있습니다. 보안 설정을 끄지 마세요. 아래 공식 저장소의 배포 파일인지 확인하세요.

공식 배포처: https://github.com/contentriumkorea/frame-fixer

## 사용법

1. 설치 후 시작 메뉴에서 **Frame Fixer**를 엽니다.
2. 영상 여러 개를 창에 끌어넣습니다.
3. 목표 FPS를 선택합니다. 기본값은 23.976fps(정확히 `24000/1001`)입니다.
4. 파일명과 저장 위치를 확인합니다. 기본 출력명은 `원본이름(23.976).mp4`이며 앞 이름과 괄호 안 이름을 수정할 수 있습니다. FPS·이름·저장 위치 변경은 모든 대기/실패 항목에 자동 반영됩니다. 분석 중이면 분석 완료 후 최신 설정을 반영하며, 이미 완료된 결과 파일과 경로는 바꾸지 않습니다. 별도의 전체 적용 버튼은 없습니다.
5. 오른쪽 아래 **N개 렌더** 또는 **렌더 시작**을 누릅니다. 파일별 진행률과 하단의 전체 진행률·경과 시간·예상 남은 시간을 확인할 수 있습니다.

오류가 있는 파일은 렌더 대상에서 제외되며 목록에 이유와 제외 개수를 표시합니다. 문제를 해결한 뒤 **실패 재시도**를 누르면 해당 항목만 다시 분석하고 정상 항목을 렌더합니다. 기존 출력 파일이 있으면 자동으로 덮어쓰거나 지우지 않으므로 출력 이름 또는 경로를 바꾸세요. 렌더 중 완료된 행을 선택하면 **결과 열기 / 폴더 열기**를 사용할 수 있습니다.

저장 공간의 권장량은 무손실 압축률을 알 수 없어 임시 파일까지 고려한 보수적 참고값입니다. 실제 결과 크기를 보장하지 않습니다. 권장량 경고는 확인 후 계속할 수 있고, 최소 여유 공간에 못 미치는 저장 장치는 렌더에서 제외합니다. 처리 중 공간 부족으로 실패하면 앱이 만든 미완성 임시 파일만 정리하며 기존 결과와 원본은 유지합니다. 일부 네트워크 드라이브에서 남은 공간을 읽을 수 없으면 확인 불가로 알립니다.

원본 파일과 기존 출력 파일을 덮어쓰지 않습니다. 기본 변환은 각 영상의 원본 픽셀 크기를 유지하므로 720p, 1080p, 4K, 세로 영상을 섞어 넣을 수 있습니다.

## AI 업스케일

출력 설정 아래 **AI 화질 개선 → SeedVR2 업스케일 사용**을 켜고 **AI 엔진 준비**를 완료하세요. 준비는 처음 한 번만 필요하며 선택은 다음 실행에도 저장됩니다. 일반 변환에는 AI 엔진이 필요하지 않습니다.

- 처리 순서: **모든 프레임 정렬·검증 → CUDA AI 업스케일 → 생성 픽셀 무손실 저장·검증**. 프레임을 추가·제거하거나 보간하지 않습니다.
- 가로 1920 / 세로 1080을 둘 다 만족하면 AI를 생략합니다. 작은 영상은 정확한 원본 비율로 두 기준을 모두 충족하도록 확대합니다. 1280×720 → 1920×1080, 960×544 → 1920×1088, 1024×768 → 1920×1440처럼 비표준 크기도 자르거나 늘이지 않습니다.
- 최초 AI 다운로드는 약 **6.88GB**, 준비 여유 공간은 **16GB 이상 권장**입니다. Python·CUDA SDK·Topaz를 따로 설치하지 않아도 됩니다. 고정 버전과 SHA-256을 확인하며 준비 실패 시 재시도·복구할 수 있습니다. 영상은 업로드하지 않습니다.
- **NVIDIA VRAM 16GB 이상 권장**, 총 12GB / 현재 여유 10GB 이상을 검사합니다. 확인 장비는 RTX 5070 Ti 16GB이며 모든 GPU·드라이버 조합을 검증한 것은 아닙니다. AI는 GPU 0을 사용합니다. 리소스 모니터의 장치 선택은 렌더 장치를 변경하지 않습니다.
- AI 생성 RGB 픽셀을 정확히 보존하기 위해 마지막 저장은 **CPU 무손실 인코딩**입니다. 이 단계까지 전부 CUDA로 동작하는 것은 아닙니다. 결과 용량과 임시 디스크 사용량이 크게 늘 수 있습니다.
- AI는 새로운 디테일을 생성합니다. 실제 원본 디테일 복원이나 모든 장면의 화질 향상을 보장하지는 않습니다. 원본 픽셀 보존이 목적이면 AI를 끄세요. 워터마크는 AI 후에 적용됩니다.
- 회전/비정사각 픽셀 메타데이터가 있는 저해상도 입력 및 비율 유지 결과가 가로/세로 8192 또는 약 3355만 픽셀을 넘는 경우에는 왜곡 없이 처리할 수 없음을 알립니다. 지원하지 않는 항목은 오류로 남기며 정상 항목은 계속 처리합니다. RGB High 4:4:4 출력은 일부 편집기에서 열리지 않을 수 있습니다.

리소스 모니터는 **PC 전체** CPU·RAM·NVIDIA GPU 연산/인코딩·VRAM을 표시합니다. 사용량이 곧 Frame Fixer 단독 점유율을 뜻하지는 않습니다. 일반 변환의 CPU fallback은 유지되지만 AI 오류 시 화질을 낮추거나 다른 모델로 몰래 대체하지 않습니다.

## 무료 이용과 오류 확인

- 활성화하지 않아도 **길이 제한 없이 모든 기능**을 사용할 수 있습니다. 무료 출력에는 중앙에 **불투명도 20%**의 Contentrium 로고가 들어갑니다. 로고는 화면 가로 약 22%이며 세로 크기도 제한합니다. 상단 **Activation**에서 **Activation Code**를 입력하고 **Activate**를 누르면 이후 출력의 워터마크가 제거됩니다. 활성화 정보는 다음 실행에도 유지되며 기존 출력 파일을 소급 변경하지 않습니다. 이 코드는 계정·결제·기기 수 제한이 아닌 오프라인 편의 기능이며, 코드 자체는 공개 안내나 오류 화면에 표시하지 않습니다.
- 변환 실패, 도구 준비, 업데이트 확인 등에서 **오류 상세**를 열면 필요한 진단 내용을 읽고 **내용 복사**로 직접 전달할 수 있습니다. 영상이나 오류 내용은 자동으로 업로드·전송하지 않습니다.
- 이전 버전의 출력 파일이나 이용 조건은 소급 변경하지 않습니다.

## 화질과 속도 (AI를 끈 일반 변환)

프레임을 삭제·복제·보간하지 않습니다. 영상 길이는 `프레임 수 ÷ 목표 FPS`로 바뀝니다. AAC 오디오는 속도를 바꾸지 않고 시작점을 영상 0초에 맞춰 복사합니다.

활성화 출력은 가능한 경우 재인코딩 없이 원본 압축 영상 데이터·프로파일을 유지하고 프레임 시간만 변경합니다. 압축 패킷과 모든 디코딩 프레임 픽셀을 검증하며, 적용할 수 없거나 검증에 실패하면 무손실 H.264 인코딩으로 전환합니다. 무료 출력은 **워터마크를 합성한 기준 영상**과 모든 디코딩 프레임 픽셀을 비교합니다. 워터마크가 들어간 부분은 의도적으로 원본과 다릅니다. 두 모드 모두 프레임 수·간격, 해상도·화면비·색 정보와 오디오를 검증한 후 저장합니다. **파일 용량·비트레이트가 아닌 실제 픽셀·오디오 보존이 기준입니다.** 작은 결과도 허용하고 빈 데이터로 용량을 채우지 않습니다. 무손실 재인코딩 결과는 용량이 크게 늘 수 있으며 원본의 100–105% 범위를 보장하지 않습니다. 프레임 시간 변경으로 재생 길이와 초당 비트레이트가 달라지는 것은 그 자체로 화질 저하를 뜻하지 않습니다.

재인코딩이 필요한 경우 호환 NVIDIA GPU는 NVENC 무손실 인코딩을 사용하며, 지원하지 않는 환경이나 입력은 CPU 무손실 인코딩을 사용합니다. GPU 실행 오류 시 CPU 무손실 인코딩으로 재시도하고 다시 검증합니다. 원본 분석과 픽셀·오디오 검증에는 CPU와 저장장치도 사용하므로 전체 시간은 인코딩 시간보다 깁니다. 별도의 CUDA SDK는 필요하지 않습니다. 남은 시간은 실제 진행에 따른 추정치입니다.

지원 입력은 MP4의 H.264 8비트 SDR, AAC 오디오 또는 무음입니다. HDR·다른 비트 심도·다른 오디오 코덱·다중 트랙 등 지원하지 않는 입력은 임의로 바꾸지 않고 오류를 표시합니다. 무손실 H.264 프로파일은 일부 플레이어·편집기에서 열리지 않을 수 있으며, Premiere의 실제 가져오기·재생 호환성은 별도 확인이 필요합니다. 원본을 계속 보관하세요.

## 업데이트

앱을 켜면 백그라운드에서 새 버전을 확인합니다. 새 버전이 있을 때만 알림을 표시하며 **지금 업데이트**를 누르면 다운로드·검증 후 설치하고 다시 시작합니다. 알림을 닫고 계속 사용할 수도 있습니다. 상단 업데이트 버튼으로 수동 확인도 가능합니다. 업데이트 목록의 RSA 서명과 설치파일의 크기·SHA-256을 확인하며, 검증에 실패하면 설치하지 않습니다. 이 검증은 Windows 게시자 인증과는 별개입니다.

분석·렌더 중에는 시작 알림과 설치를 미룹니다. 수동으로 다운로드한 동안 작업이 진행 중이라면 작업 종료 후 **설치·다시 시작**을 누릅니다. 업데이트 후 설정과 파일 목록을 보존하며 렌더는 자동으로 시작하지 않습니다. 네트워크 오류는 ‘최신 버전’으로 표시하지 않고 수동 재확인과 오류 상세를 제공합니다.

설정은 `%AppData%\FrameFixer`, 영상 도구·업데이트 캐시는 `%LocalAppData%\FrameFixerData`에 저장합니다. 제거해도 설정·캐시·원본 영상은 남습니다. 최초 도구 다운로드가 실패하면 연결 상태를 확인하고 설치를 다시 시도하세요.

## 개인정보와 제3자 도구

영상은 외부로 업로드하지 않습니다. 외부 통신은 설치 중 도구 다운로드, 앱 시작 시 자동 업데이트 확인, 사용자가 실행한 업데이트·영상 도구·AI 엔진 및 모델 다운로드에 사용됩니다. 시작 시 확인만으로 설치파일이나 AI 엔진을 자동 다운로드하거나 설치하지 않습니다.

이 저장소는 Frame Fixer 설치파일·업데이트 확인 파일·AI 런타임·안내를 배포합니다. 사용자 영상과 FFmpeg 바이너리는 포함하지 않습니다. FFmpeg/FFprobe는 [Gyan 공급처](https://www.gyan.dev/ffmpeg/builds/)의 고정 8.0 패키지에서 직접 받으며 공급처의 LICENSE·README를 로컬 도구 캐시에 보관합니다. [FFmpeg 프로젝트](https://ffmpeg.org/) 및 해당 도구의 라이선스는 각 권리자에게 귀속됩니다.

AI 모델은 공식 [SeedVR2 모델 저장소](https://huggingface.co/numz/SeedVR2_comfyUI)에서 고정된 버전으로 받습니다. 앱에 포함된 수정 SeedVR2 소스와 라이선스·변경 고지는 설치 폴더의 `ai`에, Python/PyTorch/NVIDIA/MSVC 고지는 AI 런타임에 보관합니다. [CUDA 이용 조건](https://docs.nvidia.com/cuda/archive/12.8.1/eula/index.html)과 [cuDNN 이용 조건](https://docs.nvidia.com/deeplearning/cudnn/backend/v9.10.2/reference/eula.html)을 AI 준비 화면에서도 확인할 수 있습니다.
